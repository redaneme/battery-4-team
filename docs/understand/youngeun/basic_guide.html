배터리 주문 계획, 쉽게 이해하기

3단계로 나눠 눈으로 보고 직접 눌러 보며 이해합니다. 앞에서부터 차례로 보세요.

한 줄 요약

한국 본사가 중국·일본·베트남·인도네시아 공장에 배터리 셀을 만들게 하고, 배로 한국까지 실어 오는 일정과 비용을 미리 계산해 주는 서비스입니다.

  • 1. 주문 넣기나라별로 몇 개 만들지 입력
  • 2. 계획 보기며칠 걸리고 얼마 드는지 확인
  • 3. 주문 확정마음에 드는 안을 골라 확정
  • 4. 진행 관리확정 → 진행 → 완료 추적

나라와 뱃길 살펴보기

지도의 나라를 눌러 보세요. 그 나라 공장의 능력과, 다른 나라까지 배로 며칠 걸리는지 보입니다.

꼭 알아둘 낱말 3개

K (케이)천 개 단위입니다. 3K = 배터리 셀 3,000개.
재고 상한공장이 배를 기다리며 쌓아 둘 수 있는 최대 수량. 가득 차면 생산을 멈춥니다.
기준 정보공장 능력, 뱃길 일수, 배 척수, 운항비처럼 계획 계산의 바탕이 되는 값. 관리 화면에서 바꿀 수 있습니다.

사용 약속과 입력 한도

로그인로그인한 사람만 쓸 수 있습니다. 로그인하지 않으면 로그인 화면만 보입니다.
주문 한도총 주문은 1K 이상 100,000K 이하. 나라별 수량은 0 이상.
기준 정보 한도배는 1~4척, 뱃길은 1~365일. 하나라도 잘못되면 아무것도 저장되지 않고 이유가 모두 안내됩니다.
확정 때 다시 계산확정 순간에 시스템이 같은 주문으로 다시 계산합니다. 화면에 보인 값을 그대로 믿지 않습니다.
메모확정할 때 메모를 남길 수 있고, 1,000자까지입니다.

이렇게 계획이 만들어집니다

  • 모든 공장이 0일차에 동시에 생산을 시작합니다. 하루 생산량은 공장의 하루 최대치까지, 재고 상한까지 입니다.
  • 배는 도착한 날의 재고를 전부 싣고 갑니다.
  • 재고 상한보다 많이 주문하면 여러 번 나눠 가져옵니다. 그때는 한국에 내려놓고 다시 출항합니다.
  • 배는 재고가 찰 때까지 한국에서 기다렸다가 맞춰서 늦게 출항합니다. 한국에서 기다리는 건 무료입니다.
  • 실제 서비스는 세 가지 안(운항비 최소 / 가장 빠르게 / 가까운 곳부터)을 보여 줍니다. 여기서는 이해를 돕기 위해 "가까운 곳부터" 안만 직접 계산해 봅니다.

직접 넣어 보기

계산 결과

※ 학습용 계산입니다. 기본 기준 정보(공장 능력, 뱃길 일수, 척당 하루 운항비 1억 원)를 그대로 썼습니다.

주문의 한 살이

확정된 주문은 정해진 순서로만 상태가 바뀝니다. 건너뛰거나 되돌릴 수 없습니다.

확정 → 진행 → 완료 (확정·진행 단계에서는 취소도 가능, 완료·취소 후에는 더 바꿀 수 없음)

상태가 바뀔 때마다 "누가, 언제, 무엇에서 무엇으로" 바꿨는지 이력이 남습니다.

체험: 두 담당자가 같은 주문을 동시에 본다면?

두 사람은 같은 시점의 화면을 열어 둔 상태입니다. 한 사람이 상태를 바꾼 뒤, 다른 사람(옛 화면)이 바꾸려 하면 어떻게 되는지 눌러 보세요.

실제 주문 상태:

변경 이력

    알아둘 점

    • 다른 사람이 먼저 바꿨다면, 늦은 쪽은 거부되고 화면을 새로고침해야 합니다. 서로의 변경을 덮어쓰지 않기 위함입니다.
    • 주문을 취소하면 주문 목록에서 삭제됩니다. 이력만 남습니다.

    체험: 계획을 본 뒤 기준 정보가 바뀌면?

    ①→②→③ 순서로 눌러 보세요. 확정은 계획을 본 때와 같은 기준 정보일 때만 됩니다.

    이미 확정된 주문은 이후에 기준 정보가 바뀌어도 확정 당시의 계획이 그대로 보존됩니다.

    ※ 이 안내서의 숫자는 코드의 초기값 기준이며, 운영 중 관리 화면에서 바뀔 수 있습니다.
